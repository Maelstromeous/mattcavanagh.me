# Codebase review, September 2026

Fact-finding for the move off PHP. Written 2026-09-03 against `master` at `df75c79`. Two detailed
audits sit under [`review-2026-09/`](review-2026-09/): [`deps-infra-audit.md`](review-2026-09/deps-infra-audit.md)
(dependencies, workflows, containers, security, Renovate, git history) and
[`frontend-audit.md`](review-2026-09/frontend-audit.md) (LESS, JavaScript, content inventory,
images, links, accessibility). This file is the summary. The plan that follows from it is
[`migration-plan.md`](migration-plan.md).

## What the site actually is

Two pages, `/` and `/portfolio`, served by a PHP 7.4 front controller (league/route, league/container,
zend-diactoros) that renders Twig 1 templates. No database, no forms, no sessions, no user input
of any kind. Config is three environment variables (`ENVIRONMENT`, `BASE_URL`, `VERSION`). The
only "dynamic" behaviour is the current year in a footer that CSS hides, the active nav class, and
a cache-busting query string. It is a static site with a PHP runtime wrapped around it.

The front end is Bootstrap 3.3.7 and jQuery 3.1.1 from CDNs, Font Awesome 5 from cdnjs, devicon
from a CDN that shut down in 2019, and roughly 550 lines of hand-written LESS plus 130 of jQuery.

Deployment: GitHub Actions builds a Docker image (nginx + php-fpm under runit) and pushes it to
Docker Hub. Watchtower on the host pulls it. Cloudflare fronts the domain. There is no webhook
and no SSH from CI. The only secrets in the repo settings are the two Docker Hub credentials.

Size and age: first commit 2016-07-14, 394 commits. Last feature work 2020. Last infrastructure
work January 2023. Last human commit 2025-05-04 (the employment banner). Everything since is bot
churn on dependencies that are themselves end of life. The portfolio page says "Last updated:
10/06/2020" and means it.

## Findings that matter

Ordered by what they cost, not by how they look on a scanner.

### Already broken in production

1. **The tech icons on the portfolio page do not render.** `devicon.min.css` is loaded from
   `cdn.rawgit.com`, dead since October 2019. The 1 MB of devicon font files committed under
   `assets/dist/` are referenced by nothing. `frontend-audit.md` 1.4, `deps-infra-audit.md` 5.
2. **Analytics has collected nothing since July 2023.** The Universal Analytics property is dead.
   Before that, every click event threw a `ReferenceError` because `ga.js` calls `sendEvent` but
   defines `sendGAEvent`; only the pageview ever fired. `deps-infra-audit.md` 5.
3. **The Professional tab is unreachable.** The pane exists with ten cards in it; the tab strip
   only links All, Featured and Personal. `frontend-audit.md` 3.1.
4. **The footer is hidden on every page.** `pages/landing.less` is pulled into the global
   stylesheet unscoped, so its `#footer { display: none }`, `body { background: #eee }` and
   `#header { margin-bottom: 0 }` apply site-wide. The rendered site differs from what the LESS
   reads as intended. The rebuild must reproduce the rendered result. `frontend-audit.md` 1.2.
5. **`manifest.json` is broken.** Name is the generator default "App" and every icon path points
   at the web root while the files live under `/assets/img/`. `frontend-audit.md` 4.
6. **The Ansible lint workflow fails on every push** because it targets Kubernetes playbooks
   deleted in January 2023. The README badge has been red since. `deps-infra-audit.md` 3.
7. **Headings name the Ubuntu font but never load it.** Visitors see the platform sans-serif.
   `frontend-audit.md` 1.4.

### Security posture

8. Every runtime PHP dependency is end of life or abandoned: Twig 1.42 (EOL 2020),
   zend-diactoros 1.8 (abandoned for Laminas), league/route 2.0 (2018), league/container 2.4
   (2017), PHPUnit 6 (EOL 2019), on `php:7.4-fpm` (EOL November 2022) rebuilt every Monday. Two
   `[SECURITY]` Renovate PRs are open and four major bumps already auto-closed because the lock
   cannot be resolved. `deps-infra-audit.md` 1.
9. jQuery 3.1.1 (CVE-2019-11358, CVE-2020-11022, CVE-2020-11023) and Bootstrap 3.3.7
   (CVE-2018-14041, CVE-2018-14042, CVE-2019-8331) are loaded from CDNs, five of six loads
   without subresource integrity. The site uses the affected tooltip feature. With no
   attacker-controlled markup on a static portfolio the practical risk is low, but it is why the
   scanners will not shut up. `deps-infra-audit.md` 5.
10. The CSP is a single `default-src` with `'unsafe-inline'` and nine third-party hosts, two of
    which nothing uses and one of which no longer exists. `deps-infra-audit.md` 4.
11. In the container, `www-data` has passwordless sudo and the supervisor runs as root, so any
    PHP code execution is root in the container. `deps-infra-audit.md` 4.
12. `.dockerignore` misspells `provisioning/`, so the Ansible vault sits in the Docker build
    context. It is not copied into the image, so this is latent rather than leaking. The vault's
    only consumers were deleted in 2023; it is almost certainly orphaned. Nobody but me should
    open it. `deps-infra-audit.md` 4, 5.
13. No credentials are committed anywhere outside the vault. `deps-infra-audit.md` 5.

### Dead weight

14. **40 MB of the 49 MB of images are never served.** `portfolio/originals/` holds the source
    screenshots and nothing references them. A further six images and six favicon variants are
    unused. `frontend-audit.md` 4.
15. Dead code with no matching markup: card click-through (`data-href`), the "show all
    technologies" toggle, `header.less` (unimported and would not compile), a `ps2alerts.twig`
    detail page with no route and a typo'd variable, `public/test.html`, the Prepros editor config
    with a stale import list, the committed compiled CSS and its stale source map, and eleven LESS
    rules for classes no template uses. `frontend-audit.md` "Dead weight to delete".
16. `josegonzalez/dotenv` is required and never called. `grunt-contrib-uglify` is loaded and never
    configured. `phpunit.xml` points at a `tests/` directory that does not exist. There are zero
    tests. `deps-infra-audit.md` 1, 2.
17. The deploy workflows compute a date, a short SHA and the previous tag and use none of them.
    `stop.yml` stops containers belonging to a different project. `deps-infra-audit.md` 3, 4.
18. Twelve open bot PRs, none safely mergeable: the Composer ones need a PHP 8 rewrite, the
    Actions ones target workflows that will be deleted, the Grunt ones update a toolchain that
    will be deleted. `deps-infra-audit.md` 6.

### Content and correctness

19. 59 images have no `alt`. Five `<a>` tags carry an `alt` attribute (invalid). Icon-only links
    have no accessible name. `<meta property="description">` should be `name=`, so search engines
    ignore the description. No `og:title`, no canonical. Every `target="_blank"` lacks
    `rel="noopener"`. `frontend-audit.md` 6.
20. Card data inconsistencies: `psb` sits in the Featured tab without the featured border; the
    `meynellsfencing` card loads `maynellsfencing.jpg`; `nfc` is dated "???"; two card images lack
    the cache-buster; the ps2alerts link lacks the analytics label every other card has. Seven
    spelling errors in card copy. `frontend-audit.md` 3.
21. 21 outbound links, 11 of them plain `http://`, most from 2014 to 2017. None were fetched;
    several are probably dead. Listed in `frontend-audit.md` 5 for me to check.

## What this means for the migration

- **Nothing in the PHP layer is worth porting.** It is a router with two routes and a template
  engine. The content is in 17 card templates and two pages of copy; that is what moves.
- **The CSS is small.** 12 LESS files, about 550 lines including the dead ones, one breakpoint in
  real use. Porting to SCSS is a morning, not a project. The Bootstrap 3 surface is about 15
  components and utilities and is cheaper to hand-write than to replace with Bootstrap 5.
- **The JavaScript is smaller.** Four behaviours (tooltips, tabs, hover-scroll previews, masonry
  packing) plus a mobile nav toggle. All have library-free equivalents.
- **"No visual redesign" has to mean the rendered site**, accidents included, verified by a
  screenshot diff. Then I decide, item by item, which accidents to keep. Those decisions are
  tabled in the plan.
- **Everything under `provisioning/` and `.github/workflows/` is deletable at cutover.** Vercel
  replaces the build, the registry, the host, Watchtower and staging. The `www` to apex redirect,
  the security headers (with a rewritten CSP) and the meta/favicon set are the only things the
  infrastructure layer contributes that must survive.
